The loop

Measure. Rebuild. Render. Self-review.

The agent never guesses at a style — it measures the reference, writes a machine-readable style spec, and diffs its own render against it.

01 · analyze_referenceStudy the reference

Scene cuts, fingerprinted transitions, in-shot motion, OCR'd captions, musical beats — plus filmstrips so even 2-frame flashes are visible to the agent.

02 · scaffold_reelWrite the recipe

The agent describes the new reel as plain JSON — your footage, your script, the reference's timing — and scaffolds a ready-to-edit Remotion project.

03 · render_reelRender the video

Draft renders for fast iteration, full-resolution for the deliverable. Remotion handles the pixels; the agent handles the taste.

04 · review_renderCritique itself

The render goes through the same analyzer as the reference. The diff becomes a 0–100 fidelity score with issues that name the exact recipe field to fix.

The toolbox

Twelve tools, one workflow.

Everything the agent needs to go from "make it look like that" to an mp4 — plus a /mimic-mcp slash-command prompt that walks it through the whole flow.

studyanalyze_reference

Measures the reel into a style spec: cuts, transitions, motion, captions, beats.

studytranscribe_reference

Word-level transcript of the reference, so the agent sees hook → build → payoff.

studyextract_music

Rips the soundtrack so the new reel can use the same music.

preptrim_silence

Cuts silent gaps out of talking-head footage into a tight jump-cut clip.

prepgenerate_voiceover

Script → spoken voiceover with the built-in macOS voice. No API key.

buildscaffold_reel

Style recipe in, ready-to-edit Remotion project out.

buildrender_reel

Renders to mp4 — draft for speed, final for the deliverable.

buildreview_render

Diffs the render against the reference into a fidelity score and fixes.

buildopen_in_studio

Human handoff: preview and tweak every field in Remotion Studio.

shipexport_variants

Re-frames the finished reel to 9:16, 1:1, 4:5, 16:9 for cross-posting.

reuselist_presets / get_preset

Browse reusable style presets — built-ins plus your own.

reusesave_preset

Capture a style you nailed as a named preset for future reels.

Quickstart

Hooked up in one command.

Install ffmpeg, point your agent at the published package, and ask for a reel. No clone, no build.

# prerequisites (macOS — see README for Windows/Linux)
brew install ffmpeg

# add the server
claude mcp add mimic-mcp -- npx -y mimic-reels-mcp

# then, inside Claude Code:
/mimic-mcp  my-screen-recording.mov  script.txt  reference-reel.mp4

Add to ~/.codex/config.toml:

[mcp_servers.mimic-mcp]
command = "npx"
args = ["-y", "mimic-reels-mcp"]

Add to .cursor/mcp.json (per-project) or ~/.cursor/mcp.json (global):

{
  "mcpServers": {
    "mimic-mcp": {
      "command": "npx",
      "args": ["-y", "mimic-reels-mcp"]
    }
  }
}
gemini mcp add mimic-mcp npx -y mimic-reels-mcp

It's a standard stdio MCP server. Any client that takes a command + args:

command: npx
args: [-y, mimic-reels-mcp]

Hacking on it instead? Clone, npm install && npm run build, and use node dist/index.js — see CONTRIBUTING.md.

The contract

One JSON recipe between taste and pixels.

The style recipe is what the agent writes after studying the reference — and what the renderer consumes. Everything past caption is optional; a minimal segment is just start, end, and text.

  • Karaoke & typewriter captions with per-word timings from transcription
  • Ken-Burns punch-ins with focus points and fitted easing
  • Multi-clip montages — each segment can bring its own footage
  • Transition sounds — pop, click, whoosh, riser, or your own file
  • Validated up front — scaffold_reel rejects a bad recipe before you render
{
  "output": { "width": 1080, "height": 1920, "fps": 30 },
  "background": { "video": "my-footage.mov" },
  "music": { "file": "extracted-music.m4a" },
  "segments": [{
    "start": 0, "end": 2.1,
    "caption": "3 tools that changed how I code",
    "captionStyle": "hook",
    "captionAnimation": "karaoke",
    "highlightColor": "#ffe000",
    "zoom": { "from": 1, "to": 1.3 },
    "sound": "whoosh"
  }]
}
